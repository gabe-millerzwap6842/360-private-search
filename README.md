## What Is 360?

360 provides a single web-based environment for private search, communication, information feeds, and useful online tools. Its customizable workspace is designed to reduce the need to switch between separate tabs for common tasks.

Alongside private search, the platform includes an AI assistant, live chat, news, weather, market information, translation, games, and URL shortening. The web-first experience can also be installed as a Progressive Web App, while desktop versions are available for Windows and Linux.

### Is 360 a browser or a search engine?

360 offers a browser-style workspace that combines search with several integrated services. It runs through the web and can also be accessed through supported desktop applications or PWA installations.

### Can the interface be changed?

Yes. Customization controls include themes, dark mode, and cursor-style settings.

### Are AI assistant conversations saved?

The built-in AI assistant supports conversation history and file uploads for compatible workflows.

### How many translation languages are supported?

The translation utility supports more than 80 languages.

### How do I install 360 like an application?

Install the hosted platform through the PWA option in a compatible browser, or use the Windows or Linux desktop build when available.

### What can I check when a feature fails to load?

Make sure JavaScript is turned on and that your internet connection is working. Refresh the page, verify that you are using the latest hosted build, and inspect the repository configuration when running a local copy.
